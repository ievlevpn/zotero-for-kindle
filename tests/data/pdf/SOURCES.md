# PDF test fixtures

Generated by the project (reportlab + pypdf): `sample.pdf` — 3 letter-size pages, an outline
("Chapter one/two/three"), the word "Hamiltonian" on page 2; `encrypted.pdf` — the same with the
user password "secret".

`rotated.pdf` — one letter page with real text and `/Rotate 90`; `scan.pdf` — one page that is only an image (no text layer). Both made by `make_rotated_scan.py`.

`links.pdf` — page 1 cites [1] (an internal link to the reference on page 2) and has a web link
(https://example.org/pinns); page 2 is the reference list. Made by `make_links.py`.
